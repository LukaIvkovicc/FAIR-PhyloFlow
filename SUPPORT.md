# Support

FAIR PhyloFlow is research software under active development.

- Use a GitHub issue for reproducible bugs, documentation problems, and feature
  proposals.
- Use a GitHub discussion, when enabled, for workflow-design and scientific
  methodology questions.
- Follow [SECURITY.md](SECURITY.md) for vulnerabilities.

Include the software version, workflow configuration, Python version, operating system, relevant
configuration excerpt, command, and complete error output. Remove credentials,
private paths, and sensitive unpublished data before posting.

The issue tracker is not a substitute for independent biological or statistical
review of research conclusions.
